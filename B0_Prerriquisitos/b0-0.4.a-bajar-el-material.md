## ⌨️ Comandos y pasos importantes

- `pwd` — Comprueba la ruta actual en la terminal para asegurar que estamos en la carpeta correcta (`.../Boveda_SOR/01_Practicas`).
    
      
    
- `git clone git@github.com:TU-USUARIO/nombre-repo.git Nombre_Carpeta` — Clona un repositorio mediante SSH asignándole un nombre específico a la carpeta de destino.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
- `git clone [https://github.com/TU-USUARIO/nombre-repo.git](https://github.com/TU-USUARIO/nombre-repo.git) Nombre_Carpeta` — Clona un repositorio público mediante HTTPS.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
- `git status` — Muestra el estado del árbol de trabajo (si es un repositorio Git válido y qué archivos han sido modificados o no están rastreados).
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
- `git add .` — Añade todos los cambios y nuevos archivos al área de preparación (_staging area_).
    
      
    
- `git commit -m "mensaje"` — Registra los cambios preparados en el historial local del repositorio.
    
      
    
- `git push` — Envía los commits locales al repositorio remoto en GitHub.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
- `git remote -v` — Verifica las URL remotas asociadas al repositorio para comprobar que apunta a tu usuario y no al del profesor.

## 🤔 Respuestas a las preguntas

1. **¿Qué hace `Use this template`? Después de pulsarlo, ¿sobre qué repositorio trabajas, el mío o el tuyo?** Crea una copia completamente nueva e independiente del repositorio en tu propia cuenta de GitHub, manteniendo el contenido pero generando un historial propio. A partir de ese momento trabajas sobre tu repositorio personal.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
2. **Te has bajado el Bloque 1 por HTTPS y no te ha pedido contraseña. ¿Por qué? ¿Cuándo sí te la habría pedido?** No pide contraseña porque el repositorio es público y la lectura/descarga de repositorios públicos es de acceso libre. La habría pedido si el repositorio fuera privado o al intentar realizar un `git push` para subir cambios.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    
3. **En el Explorador, la carpeta del ZIP y la carpeta clonada se ven idénticas. ¿Qué tiene una que no tiene la otra, y qué tres cosas dejas de poder hacer sin ella?** La carpeta clonada contiene la carpeta oculta `.git` (el historial de versiones), mientras que el ZIP solo contiene los archivos sueltos. Sin la carpeta `.git` no puedes:
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
    
      
    - Consultar o gestionar el historial (`git status`, `git log`).
        
          
        
    - Recuperar archivos eliminados o revertir cambios (`git restore`).
        
          
        
    - Subir tu trabajo o cambios al repositorio remoto (`git push`).
        
          
        
4. **Anotas una duda en un fichero de la práctica, en el ordenador del aula. ¿Qué tienes que hacer para encontrarla el sábado en casa?** Hacer un `git add`, un `git commit` y un `git push` desde el ordenador del aula para subir tus cambios a tu repositorio de GitHub. Luego, en casa, simplemente haces un `git pull` para descargar las anotaciones en tu ordenador.
    
    Fase_0.4.a_Bajar_El_Material_Del_Curso (3).pdf
